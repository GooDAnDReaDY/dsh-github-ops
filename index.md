# index.md — навигация по репозиторию

Внутренний файл: в npm-пакет и GitHub-зеркало не публикуется.

| Путь | Что внутри |
|---|---|
| `lib/index.js` | Хостовая половина: схема настроек, разрешение токена через сервис учётных данных, обёртка `tool()` (ошибки становятся значением), подключение регистраций |
| `lib/github.js` | Клиент GitHub: REST v3 и GraphQL v4, внедряемый транспорт, нормализация ошибок (`status`, `code`, `rateLimit`), пагинация, `parseRepoSpec` |
| `lib/tools/releases.js` | Релизы: список, чтение, создание, правка (включая `make_latest`), удаление |
| `lib/tools/tags.js` | Теги: список, создание (обычный или аннотированный), удаление |
| `lib/tools/repos.js` | Репозитории: метаданные, файл на ref (или листинг), поиск, создание, правка |
| `lib/tools/issues.js` | Issues: список/чтение с комментариями, создание, коммент, закрытие, поиск |
| `lib/tools/pulls.js` | PR: создание, правка, merge, обзорный пакет с находками, публикация обзора, checks, `ci_run` |
| `lib/tools/api.js` | `gh_api`: белый список запретов, требование `confirm` для мутаций |
| `lib/tools/actions.js` | Workflow runs: список, просмотр, jobs со упавшими шагами, rerun, cancel, ссылка на логи |
| `lib/tools/repo-settings.js` | Переменные, секреты (sealed-box через опциональный `tweetnacl`), rulesets, защита веток |
| `lib/tools/mirror.js` | Санитизированная публикация зеркала: allowlist, запреты, план, один коммит поверх зеркала, fast-forward |
| `lib/github.js` | Клиент GitHub: REST v3 и GraphQL v4, внедряемый транспорт и часы, повторы для чтения, уважение к `Retry-After` и лимитам, нормализация ошибок |
| `lib/auth.js` | Разрешение доступа: креденшел DSH → переменная окружения → сессия `gh` CLI |
| `lib/repo-context.js` | Какой репозиторий у вызова: явный, из настроек или из origin текущего checkout |
| `lib/review-rules.js` | Детерминированные правила ревью: glob-пути, серьёзность, порог большого диффа |
| `lib/present.js` | Карточки вызова и результата для инструментов |
| `lib/approval.js` | Политика подтверждений: имя действия, запрет вне `allowedActions`, обязательный вопрос для разрушительных |
| `lib/jobs.js` | Фоновые обзоры: хост-реестр или собственные записи |
| `lib/commands.js` | Слэш-команды `/pr`, `/review`, `/issue`, `/gh` (только инструкции, без записи) |
| `lib/tools/register-*.js` | Определения инструментов для агента (core, collab, ops, mirror) |
| `lib/client.js` | Карточка настроек: посадка `plugins.item` (+ строка и легаси), локали `en`/`zh`, проверка статуса снимка |
| `test/*.test.mjs` | Тесты без сети и без харнесса: клиент, релизы, теги, API, репозитории, issues, PR, ops, зеркало, карточка |
| `docs/design/DESIGN.md` | Дизайн-контракт: задача, границы, сценарии, контракт инструментов, приёмка |
| `scripts/publish-github.sh` | Канонический скрипт публикации зеркала (то же правило, что и в инструментах) |
| `CHANGELOG.md` | История релизов; текущее состояние — «в работе, релиза нет» |
